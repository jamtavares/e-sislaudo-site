## Como atualizar no GitHub Pages

1. Entre no repositório do site.
2. Faça upload da pasta `assets/`.
3. Substitua o `index.html` atual por este novo `index.html`.
4. Commit changes.
5. Aguarde o GitHub Pages republicar.
